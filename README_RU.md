# VK Ultra Downloader — Android project

Современный Android-проект для Xiaomi 15 Global (arm64-v8a), использующий бесплатную библиотеку yt-dlp-android.

## Что уже заложено
- Jetpack Compose UI в тёмном AMOLED-стиле.
- Поле ссылки и выбор качества: максимум, 4K, 1080p, 720p, 480p, 360p.
- yt-dlp engine через `dev.ffmpegkit-maintained:yt-dlp-android:2.0.2`.
- Продолжение незавершённых HTTP-загрузок включено опцией `--continue`.
- После успешного скачивания файл копируется в MediaStore: `Movies/VK Ultra`, откуда его видит Галерея.
- Поддержка передачи ссылки в приложение через Android Share.
- Только локальная обработка ссылки; пароль VK не запрашивается.

## Важные ограничения текущей версии
Это исходный проект MVP, а не проверенный релизный APK. В этой среде нет Android SDK/Gradle, поэтому APK здесь не собран и не протестирован на физическом Xiaomi 15.

Текущий API бесплатной библиотеки документирует асинхронную загрузку, но не предоставляет в README полноценного API pause/resume/cancel. `--continue` помогает продолжить поддерживаемые сервером HTTP-загрузки при повторном старте, но настоящий интерактивный pause/resume и устойчивую очередь нужно добавить через управляемый процесс/сервис и проверить на VK. Нельзя обещать паузу на любом HLS/DASH-потоке.

Авторизация VK: библиотека yt-dlp поддерживает cookie-файл в Netscape-формате; импорт cookies пока не реализован в UI. Не вводите пароль VK в сторонние формы и не передавайте cookies другим людям.

## Сборка
1. Установить Android Studio (JDK 17, Android SDK 35).
2. Открыть папку проекта.
3. Дождаться синхронизации Gradle.
4. Выполнить `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
5. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Законное использование
Скачивайте только видео, которые вы вправе сохранять. Приложение не предназначено для обхода платного доступа, DRM или иных ограничений VK.
